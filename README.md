# MySQL---Data-Querying & Aggregations-
 ## Overview -
Worked with MySQL queries using SELECT,DISTINCT, WHERE , ORDER BY , and LIMIT . Applied aggregate functions (SUM, AVG ,MIN ,MAX) , GROUP BY ,HAVING and JOINs to  filter , sort, summarize and analyze employee data .

## Topics Covered -
 - Data retrieval and filtering
 - Sorting and Limiting results
 - Aggregate functions andgrouping
 - Filtering grouped data using HAVING
 - Joining tables using INNER JOIN , LEFT JOIN ,and RIGHT JOIN

 ## Tools Used -
 - MySQL
 - MySQL Workbench
